# 📸 Panduan Foto — Edukasi Sampah

Folder ini untuk foto-foto yang dipakai di situs.

---

## Foto Profil (Section About)

**Nama file:** `foto-profil.jpg`  
**Lokasi:** `public/foto-profil.jpg`  
**Ukuran ideal:** Minimal 400×600 px, rasio 3:4 (portrait)  
**Format:** JPG atau PNG  

> Taruh foto kamu di `public/foto-profil.jpg` — langsung ganti file-nya.  
> Kalau belum ada fotonya, situs tetap tampil dengan placeholder otomatis.

---

## Kenapa di folder `public/`?

File di `public/` bisa diakses langsung via URL, contoh:
- `http://localhost:5173/foto-profil.jpg`

Sedangkan file di `src/assets/` perlu di-import dulu di kode.

---

## Aturan Penamaan File

| Foto untuk apa | Nama file yang disarankan |
|---|---|
| Foto profil pembuat | `foto-profil.jpg` |
| Logo situs | `logo.png` |
| OG image (share sosmed) | `og-image.jpg` |

> Pakai huruf kecil semua, pisah dengan tanda `-`, tanpa spasi.
